# 利用モデルを gemini-3.5-flash-lite に変更

## ステータス

承認済み

## コンテキスト

`gemini-flash-latest`（実体は Gemini 2.5 系の flash モデル）を LiteLLM 経由で
利用していたが、Gemini 側から 429（レート制限超過）が頻発するようになった。

軽量モデルへの切り替えを検討し、まず `gemini-2.5-flash-lite` を個別バージョン
指定で試したが、Google 側が既に新規利用不可にしており
（`models/gemini-2.5-flash-lite is no longer available to new users`）、
`gemini-3.5-flash-lite` への移行を促すエラーが返ってきた。

## 決定

`config.yaml` の `model_list` を以下のように変更し、`gemini-3.5-flash-lite`
を使う。

- `model_name: gemini-3.5-flash-lite`
- `litellm_params.model: gemini/gemini-3.5-flash-lite`

あわせて、claude cli 用の `.claude/gemini-settings.json` の `model` も
`gemini-3.5-flash-lite` に合わせる。

## 影響

- レート制限（429）の発生頻度が下がることを期待する。
- flash-lite は flash より応答品質・機能（thinking 等）が落ちる場合がある。
- 個別バージョン指定のため、Google が `gemini-3.5-flash-lite` を廃止すると
  再び同じ対応が必要になる。廃止が頻発する場合は
  `gemini/gemini-flash-lite-latest`（Google が常に最新の lite モデルを指す
  よう管理するエイリアス）への切り替えを検討する。
